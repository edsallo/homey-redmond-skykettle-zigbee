# Установка приложения на Athom Homey Pro (2023)

Это неофициальное приложение Homey для управления чайником REDMOND SkyKettle
RK-G211S через Zigbee-мост ESP32-C5. Прошивка ESP32-C5 и приложение из этого
репозитория протестированы совместно на **Athom Homey Pro (2023)**.

Исходный код, готовый BIN-файл и инструкция для ESP32-C5 находятся в разделе
**[Прошивка ESP32-C5](https://github.com/edsallo/redmond-kettle-esp32c5-zigbee)**.

## Что потребуется

- Athom Homey Pro (2023), добавленный в вашу учётную запись Athom;
- компьютер с macOS или Windows 10/11;
- доступ в интернет;
- Homey и компьютер в одной локальной сети;
- прошитая ESP32-C5;
- приложение
  [`com.redmond.kettle-homey-v1.0.1.zip`](https://github.com/edsallo/homey-redmond-skykettle-zigbee/releases/download/v1.0.1/com.redmond.kettle-homey-v1.0.1.zip).

## Часть 1. Подготовка macOS

### 1. Установите Node.js

1. Откройте [nodejs.org](https://nodejs.org/).
2. Скачайте версию с пометкой **LTS**. Требуется Node.js 18 или новее.
3. Откройте скачанный файл `.pkg` и выполните установку с настройками по
   умолчанию.
4. После установки закройте и снова откройте приложение **Terminal**.
5. Выполните:

```bash
node --version
npm --version
```

Обе команды должны вывести номера версий.

### 2. Скачайте приложение

1. Скачайте
   [`com.redmond.kettle-homey-v1.0.1.zip`](https://github.com/edsallo/homey-redmond-skykettle-zigbee/releases/download/v1.0.1/com.redmond.kettle-homey-v1.0.1.zip).
2. Откройте файл в Finder. macOS распакует его в папку
   `com.redmond.kettle-homey-v1.0.1`.
3. Не перемещайте и не удаляйте файлы внутри этой папки.

После этого переходите к разделу **«Установка Homey CLI»**.

## Часть 2. Подготовка Windows 10/11

### 1. Установите Node.js

1. Откройте [nodejs.org](https://nodejs.org/).
2. Скачайте установщик Windows для версии **LTS**. Требуется Node.js 18 или
   новее.
3. Запустите файл `.msi` и оставьте настройки установки по умолчанию.
4. Закройте и снова откройте **PowerShell**.
5. Выполните:

```powershell
node --version
npm --version
```

Обе команды должны вывести номера версий.

### 2. Скачайте приложение

1. Скачайте
   [`com.redmond.kettle-homey-v1.0.1.zip`](https://github.com/edsallo/homey-redmond-skykettle-zigbee/releases/download/v1.0.1/com.redmond.kettle-homey-v1.0.1.zip).
2. В Проводнике нажмите на архив правой кнопкой мыши и выберите **Извлечь всё**.
3. Откройте полученную папку `com.redmond.kettle-homey-v1.0.1`.
4. В ней должны находиться файлы `app.json`, `package.json` и папка `drivers`.

## Часть 3. Установка Homey CLI

Откройте Terminal в macOS или PowerShell в Windows и выполните:

```text
npm install --global --no-optional homey
```

Проверьте результат:

```text
homey --version
```

Если команда `homey` не найдена, закройте терминал, откройте его заново и
повторите проверку.

## Часть 4. Авторизация и выбор Homey

### 1. Войдите в Athom

Выполните:

```text
homey login
```

1. В браузере откроется страница Athom.
2. Войдите под той же учётной записью, к которой привязан Homey Pro (2023).
3. Подтвердите разрешение для Homey CLI.
4. Вернитесь в Terminal или PowerShell после успешной авторизации.

### 2. Выберите нужный Homey

Выполните:

```text
homey select
```

Если в аккаунте несколько Homey, выберите стрелками нужный **Homey Pro (2023)**
и подтвердите выбор клавишей Enter.

## Часть 5. Установка приложения на Homey

### 1. Откройте папку приложения в терминале

В macOS введите `cd`, поставьте пробел, перетащите папку
`com.redmond.kettle-homey-v1.0.1` из Finder в окно Terminal и нажмите Enter.

Получится примерно такая команда:

```bash
cd ~/Downloads/com.redmond.kettle-homey-v1.0.1
```

В Windows откройте распакованную папку в Проводнике, щёлкните адресную строку,
скопируйте путь и выполните в PowerShell:

```powershell
cd "$HOME\Downloads\com.redmond.kettle-homey-v1.0.1"
```

Путь может отличаться. После перехода проверьте содержимое:

macOS:

```bash
ls
```

Windows:

```powershell
dir
```

В списке должны быть `app.json` и `package.json`.

### 2. Установите зависимости

```text
npm install
```

Первое выполнение может занять несколько минут. Предупреждения `npm WARN` сами
по себе обычно не означают ошибку.

### 3. Проверьте сборку

```text
npm run build
```

Команда должна завершиться без сообщения `error`.

### 4. Установите приложение

Выполните:

```text
homey app install
```

Homey CLI проверит приложение, соберёт его и отправит на выбранный Homey.
Дождитесь сообщения об успешной установке и возвращения командной строки.

### 5. Проверьте установку

1. Откройте мобильное или веб-приложение Homey.
2. Перейдите в **Подробнее → Приложения**.
3. В списке должно появиться приложение для чайника REDMOND SkyKettle.

## Часть 6. Добавление ESP32-C5 в Homey по Zigbee

### 1. Подготовьте ESP

1. Подайте постоянное питание на прошитую ESP32-C5 через разъём `UART`.
2. Разместите ESP рядом с Homey для первого Zigbee-подключения.
3. Если ESP ранее состояла в другой Zigbee-сети, удерживайте `BOOT` не менее
   10 секунд.
4. После красного сигнала отпустите `BOOT`. ESP перейдёт в режим присоединения к
   новой Zigbee-сети; её индикатор будет мигать фиолетовым.

### 2. Добавьте устройство

1. В Homey откройте **Устройства**.
2. Нажмите **+**.
3. Найдите установленное приложение для чайника.
4. Выберите устройство **SkyKettle RK-G211S**.
5. Запустите подключение и дождитесь окончания поиска.
6. Homey должен определить устройство с производителем `EdS Home` и моделью
   `RK-G211S-ZB`.
7. Выберите комнату и завершите добавление.

После успешного Zigbee-подключения, но до соединения с чайником, индикатор ESP
может светиться жёлтым.

## Часть 7. Подключение чайника к ESP

1. Поставьте чайник на подключённую к электросети базу.
2. Разместите ESP в пределах 1–2 метров от чайника.
3. На чайнике удерживайте именно кнопку **«Вкл/Выкл»** около 5 секунд.
4. После трёх коротких звуковых сигналов отпустите кнопку.
5. Подождите, пока ESP найдёт `RK-G211S`, выполнит авторизацию и сохранит адрес
   чайника.
6. Когда Zigbee и Bluetooth-соединение с чайником установлены, индикатор ESP
   станет зелёным.

Bluetooth компьютера или телефона для этого не используется.

## Часть 8. Проверка работы

Откройте устройство `SkyKettle RK-G211S` в Homey и последовательно проверьте:

1. отображение текущей температуры воды;
2. кнопку включения — чайник должен перейти к обычному кипячению до 100 °C;
3. кнопку выключения — нагрев должен прекратиться;
4. выбор 40, 55, 70 или 85 °C;
5. установку произвольной температуры от 40 до 100 °C;
6. настройку времени поддержания температуры в расширенных настройках
   устройства — от 1 до 15 минут;
7. восстановление связи после краткого снятия чайника с базы и возврата обратно.

## Обновление приложения

Для обновления скачайте новый выпуск, распакуйте его и повторите из его папки:

```text
npm install
npm run build
homey app install
```

Поскольку идентификатор приложения остаётся прежним, существующее устройство и
Flows обычно сохраняются. Перед важным обновлением рекомендуется создать
резервную копию Homey.

## Решение распространённых проблем

### `node`, `npm` или `homey` не найдены

Закройте Terminal/PowerShell, откройте заново и повторите команду. Если это не
помогло, переустановите Node.js LTS, затем Homey CLI.

### Homey CLI использует другую учётную запись

```text
homey logout
homey login
homey select
```

### `homey app install` запущена не из той папки

Перейдите в папку, где непосредственно лежат `app.json` и `package.json`, затем
повторите команду.

### Homey не находит ESP

Убедитесь, что приложение установлено, ESP получает питание и мигает
фиолетовым. Затем удерживайте `BOOT` не менее 10 секунд и повторите добавление.

### Устройство добавлено, но чайник недоступен

Это означает, что Zigbee работает, но ESP ещё не подключилась к чайнику по
Bluetooth. Повторите процедуру из части 7 рядом с чайником.
